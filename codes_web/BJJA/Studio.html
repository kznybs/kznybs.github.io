Upgrades • Etapa 5

Conector Microsoft Lists, SharePoint & Power Automate

Configure um Webhook HTTP do Power Automate para enviar automaticamente os dados e o status de cada comunicado gerado.

Como conectar ao Microsoft Lists em 3 minutos:

  1. No Power Automate, crie um fluxo automatizado com o gatilho "Quando uma solicitação HTTP é recebida".
  2. Copie o Schema JSON gerado ao lado e cole no campo de esquema do gatilho.
  3. Adicione a ação "Criar item (SharePoint / Microsoft Lists)" mapeando as colunas do comunicado.
